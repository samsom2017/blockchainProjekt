## ?? CUSTOMIZATION

### **Change Colors**
In WebServer.java, modify CSS variables:
```css
:root {
    --primary: #your-color;
    --secondary: #your-color;
}
```

### **Change Animation Speed**
```css
--transition: all 0.1s; /* Faster */
--transition: all 0.5s; /* Slower */
```

### **Change Spacing**
```css
.container { padding: 40px 20px; }
.stat-card { padding: 30px; }
```
