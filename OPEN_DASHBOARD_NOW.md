## ?? TROUBLESHOOTING

### **"Cannot connect"**
- Make sure Java terminal is still open
- Check that you visited http://localhost:8080 (not https)
- Try refreshing the page

### **"Port already in use"**
- Close other applications using ports 8080, 8888, or 9999
- Restart your computer

### **"No events showing"**
- Wait a few seconds for system to initialize
- Click "Refresh Data" button
- Check Java terminal for errors

### **"Page looks broken"**
- Try a different browser
- Clear your browser cache
- Restart the Java application
