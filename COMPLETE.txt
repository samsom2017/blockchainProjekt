## ?? KEY CONCEPTS

### **EDSC (Event-Driven Smart Contract)**
- Records all system events
- Uses SHA-256 hashing
- Maintains immutable chain
- Validates event integrity

### **Broker**
- Manages patient-hospital mapping
- Routes vital signs data
- Broadcasts to all hospitals
- Multi-threaded listener

### **Hospital**
- Admits patients
- Sends to broker
- Receives data back
- Tracks patient information

### **BlockchainEvent**
- Represents one event
- Has hash and previous hash
- Stores timestamp
- Contains event data
